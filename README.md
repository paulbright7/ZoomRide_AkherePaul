# ZoomRide_AkherePaul
## Project Overveiw 
This project analyzes a transportation company called ZoomRide operation accross six cities to understand the performance accross these cities and to know where necessary adjustment are needed to be made
This project is also part of my data analytics portfolio showcasing Exploratory Data Analysis(EDA) Skills in MySQL.

## Busniess Question Answered
- Which city generate more revenue and completed trips
- Which month of the year generate more revenue
- which vehicle generate more revenue
- Top 3 Customers by Total Money Spend
## Key KPI
- Total Revenue
- Number of cities
- Number of Vehicle type
